First time? Start here.

Open Terminal. With the extracted folder in Downloads, paste:

cd "$HOME/Downloads/LunaShift_v5"
bash Enable_SPICE_Mac.sh

Next time, use Start_Mac.command, or run .venv/bin/python run.py from this folder.

Inside the extracted folder, double-click Enable_SPICE_Windows.bat. Python 3.10 or newer must already be installed.

Next time, use Start_Windows.bat. It automatically uses the private environment created by setup.

Open the supplied LunaShift_v5_Colab.ipynb. Keep INSTALL_SPICE = True and DOWNLOAD_SPICE_KERNELS = True in the launch cell. Upload LunaShift_v5.zip when asked.

Save your workspace before disconnecting. Colab can remove the runtime and its downloaded files.

What files are installed? Sources, model and scientific limits

This release uses a pinned DE421 set so it matches the platform's MOON_ME_DE421 coordinates. It is not advertised as the newest planetary model. Source files, hashes, frame, time conversion and correction settings are recorded with each prepared track.

SPICE locates the Sun and Earth; it does not supply mountains or crater rims. Real terrain is a separate requirement. Near-horizon accuracy also depends on terrain sampling, observer height and the model assumptions.

The words, in plain English

Azimuth

The direction around the horizon: north is 0°, east is 90°, south is 180°, west is 270°.

Elevation angle

How high something is above the local horizontal plane. This is an angle, not terrain height in metres.

Terrain skyline

The highest apparent ground angle in each direction. A distant ridge can block a low Sun.

Earth visibility

The centre of Earth clears the modeled skyline and your margin. This alone does not guarantee a radio link.

Within your limits

All enabled checks pass for this dataset and mission. It is not a statement that a real landing is safe.

Missing data

The app cannot answer from the inputs provided. It does not treat an unknown result as a failure or a success.

What this version does — and does not do

Implemented

Site/date comparison, terrain-aware visibility, tested site/time/height changes, source labels, imports, exports, local autosave, and a printable report.

Not implemented or certified

Flight-qualified power, specific ground-station access, fading, thermal dynamics, uncertainty ensembles, global optimization, or flight validation. Energy/RF screening is available on the Power & Communications page.
