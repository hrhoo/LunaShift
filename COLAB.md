# Google Colab quick start
1. Open https://colab.research.google.com/ and choose File > Upload notebook.
2. Upload LunaShift_v5_Colab.ipynb.
3. Run Upload and launch; upload LunaShift_v5.zip when asked.
4. Leave INSTALL_SPICE, DOWNLOAD_SPICE_KERNELS and INSTALL_REAL_DATA True for the full setup.
5. Use a CPU runtime. Open Mission Setup to choose Automatic, Horizons or SPICE.
6. Download your workspace before disconnecting. Colab files and installed kernels are temporary.

First setup needs internet. Offline/local SPICE means local to Google's running VM, not your Mac. The notebook is syntax-validated but was not run in a signed-in Google account during this build.
