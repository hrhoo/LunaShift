Mac: enable SPICE and launch

Extract the ZIP into Downloads. Open Terminal and paste:

cd "$HOME/Downloads/LunaShift_v5"
bash Enable_SPICE_Mac.sh

The first run installs Python support and about 19 MB of NASA files. Then the app opens. Later use:

cd "$HOME/Downloads/LunaShift_v5"
.venv/bin/python run.py

Open http://127.0.0.1:8765. Keep Terminal open. Control+C stops it.

Windows

Install Python 3.10 or newer, extract the ZIP, and double-click Enable_SPICE_Windows.bat. Later use Start_Windows.bat. Keep the command window open.

Google Colab

Upload LunaShift_v5_Colab.ipynb to Colab. Run Upload and launch, then upload LunaShift_v5.zip. Leave all three setup flags True. Use a CPU runtime. Download your workspace before disconnecting.

Which source should I choose?

Automatic is the easiest start: ready local SPICE first, otherwise Horizons. Horizons asks JPL online. SPICE calculates locally after setup. Explicit choices never secretly switch to another engine.

In Mission Setup select your date and press Prepare Sun & Earth data. Then read the actual attached source. In Data & Sources, SPICE made simple tells you whether setup and date coverage are ready.

Real sky data still need real terrain. SPICE does not turn the teaching landscape into the Moon.

What was checked?
